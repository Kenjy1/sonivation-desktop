# Sonivation pour Windows et Mac

L'application de bureau de [Sonivation](https://sonivation.ca) : depuis votre téléphone, vous demandez, et Sonivation le fait sur votre ordinateur. Retrouver un fichier, le ranger, l'ouvrir, le mettre à la corbeille, toujours avec votre accord avant de jeter ou de déplacer quoi que ce soit. Elle parle français, anglais, espagnol, portugais et allemand.

**Télécharger :** [pour Windows](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Setup.exe) · [pour Mac](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Mac.dmg)

## Installer sur Windows

1. Ouvrez le fichier téléchargé.
2. Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
3. Dans l'application, cliquez sur « Relier cet ordinateur ». Votre navigateur s'ouvre sur Sonivation : vérifiez que le code est le même, puis autorisez.

## Installer sur Mac

1. Ouvrez l'image disque et glissez Sonivation dans Applications.
2. Au premier lancement, macOS refuse de l'ouvrir : allez dans Réglages Système › Confidentialité et sécurité, puis cliquez sur « Ouvrir quand même ».
3. Dans l'application, cliquez sur « Relier cet ordinateur ».
4. Pour montrer votre écran pendant les tâches, autorisez Sonivation dans Réglages Système › Confidentialité et sécurité › Enregistrement de l'écran.

Votre ordinateur doit être allumé pendant les tâches.

# Sonivation for Windows and Mac

The [Sonivation](https://sonivation.ca) desktop app: ask from your phone, and Sonivation does it on your computer. Find a file, tidy it up, open it, move it to the trash, always with your go-ahead before throwing away or moving anything. It speaks French, English, Spanish, Portuguese and German.

**Download:** [for Windows](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Setup.exe) · [for Mac](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Mac.dmg)

## Install on Windows

1. Open the downloaded file.
2. Windows may show “Windows protected your PC”. Click “More info”, then “Run anyway”.
3. In the app, click “Link this computer”. Your browser opens Sonivation: check that the code matches, then allow.

## Install on Mac

1. Open the disk image and drag Sonivation to Applications.
2. The first time, macOS refuses to open it: go to System Settings › Privacy & Security, then click “Open Anyway”.
3. In the app, click “Link this computer”.
4. To show your screen during tasks, allow Sonivation under System Settings › Privacy & Security › Screen Recording.

Your computer must be on during tasks.
