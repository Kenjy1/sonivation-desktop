# Sonivation pour Windows

L'application de bureau de [Sonivation](https://sonivation.ca) : depuis votre téléphone, vous demandez, et Sonivation le fait sur votre ordinateur. Retrouver un fichier, le ranger, l'ouvrir, le mettre à la corbeille, toujours avec votre accord avant de jeter ou de déplacer quoi que ce soit.

**Télécharger :** [Sonivation-Setup.exe](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Setup.exe)

## Installer

1. Ouvrez le fichier téléchargé.
2. Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
3. Dans l'application, cliquez sur « Relier cet ordinateur ». Votre navigateur s'ouvre sur Sonivation : vérifiez que le code est le même, puis autorisez.

Votre ordinateur doit être allumé pendant les tâches.

# Sonivation for Windows

The [Sonivation](https://sonivation.ca) desktop app: ask from your phone, and Sonivation does it on your computer. Find a file, tidy it up, open it, move it to the recycle bin, always with your go-ahead before throwing away or moving anything.

**Download:** [Sonivation-Setup.exe](https://github.com/Kenjy1/sonivation-desktop/releases/latest/download/Sonivation-Setup.exe)

1. Open the downloaded file.
2. Windows may show “Windows protected your PC”. Click “More info”, then “Run anyway”.
3. In the app, click “Link this computer”. Your browser opens Sonivation: check that the code matches, then allow.

Your computer must be on during tasks.
